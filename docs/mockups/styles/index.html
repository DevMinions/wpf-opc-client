Dc — 视觉风格对比

同一个仪表盘,3 种设计语言。每张点进去右上角能切亮/暗。挑一个你喜欢的调子,我就照它把 13 个界面统一落地到 WPF。

A · 中后台 / Antd · Element 风

深色侧栏 + 白底主区 + 蓝色主色,信息密集、表格为王。国产工业/管理软件最常见的调子。
参考类似软件:EMQX Dashboard、ThingsBoard、各类组态/网关后台
对应 HandyControl

B · Material Design

顶部彩色 App Bar + 圆角卡片 + 明显阴影 + 鲜艳强调色,谷歌风。圆润、年轻。
参考类似软件:Grafana(部分)、Node-RED、各类 IoT 平台仪表盘
对应 MaterialDesignInXAML

C · Fluent（现状 · 参照）

Win11 原生风:Mica 半透明、轻边框、克制配色。就是现在做好的这套。
参考类似软件:Win11 自带工具、PC Manager、新版记事本
对应 wpfui（现用）
